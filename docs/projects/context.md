# Project Context

## Motivation

I am a Software Engineer with 4+ years of experience,
primarily working with Ruby/Rails, APIs, integrations,
databases, cloud infrastructure, Kubernetes and Terraform.

I am preparing for backend/software engineering opportunities
in Europe.

I have used technologies such as Redis, Pub/Sub, Kubernetes,
Terraform and observability platforms professionally, but often
through infrastructure and abstractions already created by
other teams.

This project exists to develop deeper ownership of:

- Java
- Spring Boot
- Kafka
- Event-driven architecture
- Redis
- AWS
- Distributed systems
- Reliability
- System Design

The goal is not merely to learn technologies, but to understand:

- what problems they solve;
- when to use them;
- alternatives;
- trade-offs;
- failure modes;
- operational implications.
