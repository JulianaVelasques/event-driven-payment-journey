Java source code is not directly executed by the operating system in the same way a native binary would be.

The JVM acts as the execution layer. `javac` transforms this into bytecode. The JVM is responsible for executing this bytecode.

- JVM = Java Virtual Machine.

It is the virtual machine that executes Java bytecode.

| Write once, run anywhere

Bytecode can be executed by an appropriate JVM on different platforms.

- JRE: Used to run Java applications.

- JDK: Used to develop Java applications.
